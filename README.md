# SkillSync LMS

SkillSync is a full-stack Learning Management System built with the MERN stack. It enables educators to create and manage courses, and students to enroll, learn, and earn certificates upon completion.

---

## Live Demo

Frontend: https://skillsync-lms-theta.vercel.app  
Backend: https://skillsync-backend-c57c.onrender.com

---

## Tech Stack

- Frontend: React 19, Vite, Tailwind CSS, Redux Toolkit
- Backend: Node.js, Express 5, MongoDB, Mongoose
- Auth: JWT with httpOnly cookies
- Storage: Cloudinary
- Payments: Razorpay
- Email: Nodemailer
- Certificates: PDFKit

---

## Features

- Student enrollment with Razorpay payment integration
- Video lectures with progress tracking
- Course completion certificate generation and download
- Educator dashboard to create and manage courses
- Role-based access control for students and educators
- OTP-based forget password flow
- Fully responsive design

---

## Getting Started

1. Clone the repository and install dependencies for both frontend and backend
2. Create a `.env` file in the backend folder using the variables listed below
3. Run the backend with `npm run dev` and the frontend with `npm run dev`
